One line of horror, under 200 characters, for make.fun's
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
bounty. A judge model reads the lines two at a time and picks the scarier
one, weighing how frightening, vivid, original, and well-built each sentence
is. The $5 prize pool is escrowed on chain.

## The line

> At 3 a.m. the smoke alarm whispered my name, calmly, like it had been
> practicing it all night.

Why this line: a smoke alarm is an object that should never speak, so the
moment it whispers a name the reader knows something is wrong in the house.
The detail is concrete (3 a.m., a name whispered, calmly), the turn is
fresh (no mirror, no doll, no basement), and the last words — "practicing
it all night" — land the dread: whatever it is has been listening, and
rehearsing, for hours.

## How it runs

`main.py` writes the line to `$OUTPUT_PATH/entry.txt` (default `/output`),
one sentence, UTF-8, well under the 200-character gate. Run it with:

```sh
python3 main.py
```
